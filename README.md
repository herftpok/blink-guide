# blink · гид по местам притяжения

Прототип раздела для гео-соцсети Blink: гид по ночным местам города,
собранный из аномальных скоплений пользователей в ночи пятницы и субботы.

Открыть: https://herftpok.github.io/blink-guide/

## Что внутри

- **топ мест города** — рейтинг по числу ночных посещений, с лицами друзей,
  которые там были;
- **карточка места** — чекины оттуда, кто из друзей был, маршрут и «позвать»;
- **топ тусовщиков** — лента по всему городу и среди друзей;
- **куда сходить с друзьями** — места, где друзья были, а ты ещё нет;
- **шеринг-экран «ночная личность»** — архетип, персентиль, прогресс по гиду
  и список своих мест; собран под сторис.

Переключатель городов: москва, спб, екб, казань.

## Важно

Все данные — **моковые**, лежат в `nightlife-data.js`. Названия заведений
настоящие, но **адреса и цифры проставлены вручную и не проверялись**:
перед любой публикацией их нужно подтянуть из реальной базы POI.

Страница закрыта от индексации (`robots.txt` + `noindex`).
